# Картинки для превью «Авандок.Пульс»

Файлы для карточки ссылки в мессенджерах и соцсетях.

Лежат здесь, а не на самом сайте, по одной причине: загрузчик
Telegram не может достучаться до сервера в России — проверено, в
журнале сервера ноль его обращений, при этом чужие картинки он
скачивает. GitHub ему доступен.

`pulse-2026-cover.jpg` — 1200×630, подставляется в og:image на
https://avandoc.online

Адрес для вставки:
https://raw.githubusercontent.com/Muzharov-D/kartinka/main/pulse-2026-cover.jpg

Файл собирается скриптом `art.py` (функция `og_cover`) в проекте
лендинга. Меняете картинку — держите то же имя файла, иначе
превью придётся выбивать из кэша соцсетей заново.
